About ZipShare

Mission

Give students one simple place to find and share programs, notes, assignments, and lab resources — no more hunting through chat threads for a file someone sent last semester.

Features

  • Folder uploads with preserved structure
  • Instant search with smart tag matching
  • In-browser preview for code, PDFs & images
  • Pinned & most-downloaded highlights
  • Admin-only file management

Technology Stack

Node.js · Express.js · MongoDB · Multer · Vanilla JS
